# PolyWordlot User Manual

This manual explains how to use the PolyWordlot web app: create an account, play daily or training games, navigate dates, and view statistics.

## 1. Overview
PolyWordlot is a multi-language word puzzle game with daily puzzles, training mode, a calendar view for past days, and detailed statistics. Your progress is saved automatically when you are logged in.

## 2. Account and Access

### Create an Account
1. On the login screen, click **Register**.
2. Enter your email and a password (minimum 6 characters).
3. Click **Register** to create the account and sign in.

### Log In
1. Enter your email and password.
2. Click **Login**.

### Log Out
- Click the **Logout** icon in the header.

### Forgot Password / Reset Password
1. Click **Forgot password?** on the login screen.
2. Enter your email and click **Send Reset Link**.
3. Open the email, click the reset link, and set a new password.
4. You will be redirected back to the login screen.

## 3. Game Modes

### Daily Mode
- One puzzle per day for each language and word length.
- You can navigate to previous days and replay or review them.
- Progress is saved and shown in the calendar and statistics.

### Training Mode
- Generates a random word each time you start a new game.
- Not tied to a date.
- Training games do not appear in the calendar or statistics.

Use the **Daily/Training** dropdown in the header to switch modes.

## 4. How to Play

1. Start typing a guess (either the on-screen keyboard or your physical keyboard).
2. The game starts automatically on the first letter.
3. Press **Enter** to submit a guess.
4. Press **Backspace** to delete letters.

### Guess Feedback
After each guess, letters are marked to show:
- Correct letter in the correct position
- Correct letter in the wrong position
- Letter not in the word

### Invalid Words
If a guess is not a valid word, the current row shakes and the guess is not submitted.

### Winning and Losing
- You win by guessing the word within 6 attempts.
- If you run out of attempts, the correct answer is shown.

## 5. Language and Word Length

### Choose Language
- Use the language dropdown in the settings area.
- A **Help** icon appears next to the language selector and provides language-specific tips.

### Choose Word Length
- Use the word length dropdown in the settings area.
- Supported lengths depend on the selected language.

### Language Selection Menu (Options)
1. Click the **Options** (gear) icon in the header.
2. Select which languages should appear in the main language dropdown.
3. Click **Save**.
4. At least one language must remain selected.

## 6. Date Navigation (Daily Mode)

You can move between dates only in Daily mode.

### Date Controls
- Use the **left/right arrows** to go to the previous/next day.
- Click the date field to open the calendar.
- Dates cannot be set in the future.

### Swipe Navigation
- Swipe left/right on the game area to move between days.
- Swipe navigation is only allowed when the current game is complete.
- Avoid starting a swipe on buttons, selects, or popups.

## 7. Calendar View

Open the calendar by clicking the date field.

### Calendar Behavior
- Shows a full monthly view.
- Future dates are hidden or disabled.
- Days are color-coded by status (won, lost, incomplete, or not played).
- Clicking a day selects that date and returns to the game view.
- Use **Today** to jump back to the current date.
- Use **Close** to dismiss the calendar.

While the calendar is open, the settings controls are visually greyed out to prevent changes.

## 8. Statistics

Open **Statistics** from the header tabs.

### What It Shows
Statistics are calculated only for completed Daily games.

### Filters
- Language selector
- Word length selector
- Statistic type selector

### Available Charts
- Attempts Distribution
- Running Daily Average
- Calendar Weekly Average
- Calendar Monthly Average
- Calendar Yearly Average
- 2-Week Running Average
- 4-Week Running Average

## 9. Preferences and Data Behavior

### Saved Preferences
- Selected language
- Word length
- Training/Daily mode
- Filtered language list (Options)
- Last selected date per language and word length

### In-Progress Game Safety
- Daily games are saved automatically.
- If the daily answer changes after you started a game, the unfinished game is cleared and reset to the new daily answer.

## 10. Tips and Troubleshooting

### Calendar Does Not Open
- The calendar opens from the date field in Daily mode only.
- If the calendar is already open, close it first to re-enable settings.

### Cannot Navigate to Future Dates
- Future dates are intentionally disabled in Daily mode.

### Swipe Not Working
- Swipe only works in Daily mode and only when the current game is complete.
- Start the swipe on the game board area, not on buttons or dropdowns.

### Password Reset Issues
- Make sure the reset link is opened in the same browser session.
- Passwords must be at least 6 characters.
